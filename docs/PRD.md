# AI 个性化学习资源分享平台 PRD

## 1. 产品目标

面向大学生构建一个集资源分享、智能搜索、个性化推荐、AI 辅助学习于一体的学习资源平台。

核心目标：

- 让学习资源更容易被发现、筛选和复用
- 让用户能通过自然语言和 AI 直接交互
- 让发布者和学习者形成可持续的社区互动

## 2. 目标用户

| 用户类型 | 主要诉求 |
|------|------|
| 普通学习者 | 快速找到高质量资源，获得推荐和学习建议 |
| 资源发布者 | 方便发布资源，获得浏览、点赞、收藏和评论反馈 |
| 管理员 | 审核资源、管理用户、维护分类和标签体系 |

## 3. 核心功能

### 3.1 资源管理

- 资源发布：标题、分类、标签、描述、文件或外链、封面图
- 资源浏览：首页、搜索页、详情页、个人中心
- 资源状态：草稿、待审核、已发布、已拒绝

### 3.2 搜索与推荐

- 关键词搜索与多维筛选
- AI 自然语言搜索
- 个性化推荐与相关推荐
- AI 推荐理由降级兜底

### 3.3 AI 能力

- AI 智能摘要
- AI 自然语言搜索解析
- AI 悬浮聊天窗
- 聊天流式输出、重试、失败提示

### 3.4 社区互动

- 点赞、收藏、评分
- 一级评论与回复
- 评论提交和回复的前端反馈

## 4. 关键流程

### 4.1 学习者流程

需求产生 -> 首页浏览或搜索 -> AI 推荐 / AI 搜索 -> 查看资源详情 -> 下载 / 收藏 / 点赞 / 评论 -> 继续与 AI 对话

### 4.2 发布者流程

登录 -> 发布资源 -> 系统先写本地摘要 -> 后台异步刷新 AI 摘要 -> 资源上架或待审核 -> 接收互动反馈
