# AI 个性化学习资源分享平台设计文档

## 1. 技术架构

前端：

- Vue 3
- TypeScript
- Tailwind CSS
- Pinia
- Vue Router
- Axios

后端：

- Spring Boot 3
- Spring Security + JWT
- MyBatis-Plus
- Redis
- MySQL 8.0

AI 能力：

- DashScope OpenAI 兼容接口
- AI 摘要、自然语言搜索、推荐理由、聊天流接口

## 2. 系统分层

- 表现层：Vue 页面、组件、悬浮聊天窗
- 接口层：Controller 提供 RESTful API
- 业务层：Service 负责资源、搜索、推荐、互动、AI 调用
- 数据层：MyBatis-Plus Mapper + MySQL
- 缓存层：Redis 用于 AI 响应、推荐列表、搜索历史等

## 4. API 设计

关键接口：

- 认证：`/api/v1/auth/*`
- 资源：`/api/v1/resources/*`
- 搜索：`/api/v1/search`、`/api/v1/search/nl`
- AI：`/api/v1/ai/summary`、`/api/v1/ai/recommendations`、`/api/v1/ai/chat/stream`
- 互动：点赞、收藏、评分、评论
- 管理后台：`/api/v1/admin/*`

## 5. 关键设计决策

- 资源发布时先写本地摘要，再异步刷新 AI 摘要，避免 AI 阻塞主流程
- 自然语言搜索采用本地规则优先，AI 解析作为增强
- 推荐结果采用标签权重与协同过滤混合打分
- AI 聊天采用真实模型回复优先，支持重试与错误透传
- 点赞与评论计数以业务统计字段维护，不再简单重算为历史交互表计数
