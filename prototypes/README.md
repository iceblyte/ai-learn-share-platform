# 页面原型说明

本目录包含「AI 个性化学习资源分享平台」的 6 个核心页面 HTML 原型，是产品交付物中的“需求原型”。

## 页面清单总览

| 文件 | 页面 | 核心内容 |
|------|------|---------|
| `index.html` | 首页 | 顶部导航 + 搜索栏 + 分类导航 + AI 推荐区（含推荐理由） + 热门资源 + 最新资源 |
| `search.html` | 搜索结果页 | AI 搜索解析提示 + 左侧筛选面板（分类/标签/评分/类型） + 排序切换 + 结果列表 |
| `detail.html` | 资源详情页 | 面包屑 + 资源信息 + AI 智能摘要 + 描述 + 文件下载 + 点赞/收藏/评分操作栏 + 评论区（含回复） + 侧栏推荐 |
| `publish.html` | 发布资源页 | 标题 + 分类选择 + 标签输入 + Markdown 编辑器 + 文件/链接切换 + 文件上传 + AI 摘要提示 + 提交 |
| `profile.html` | 个人中心 | 左侧资料卡 + 导航 + 我的发布列表（含状态标签） + 学习统计卡片 |
| `admin.html` | 管理后台 | 深色侧边栏 + 仪表盘统计卡片 + 待审核资源快速操作 + 最近注册用户 + 分类树管理 + 标签管理 |

## 技术说明

- 使用 Tailwind CSS (CDN) 构建，浏览器直接打开即可预览
- 遵循设计文档中的色彩系统：主色 `#3B82F6`、成功色 `#10B981`、警告色 `#F59E0B`、错误色 `#EF4444`
- 字体：Inter（英文）+ 系统默认（中文）
- 所有页面为静态原型，数据为模拟数据，无实际交互逻辑

## 页面清单

### 1. 首页 (`index.html`)

**路由**: `/`

**布局结构**:
```
├── 顶部导航栏 (Logo, 搜索框, 发布资源, 用户头像)
├── 分类导航条 (全部/计算机科学/数学/语言学习/...)
├── AI 推荐区域 (3 列卡片，含个性化推荐理由)
├── 热门资源 (4 列卡片，支持 本周/本月/全部 切换)
└── 最新资源 (4 列卡片，含时间标签)
```

**核心交互**:
- 搜索框支持自然语言输入，带 `AI` 标识
- 推荐卡片底部展示 AI 生成的推荐理由文案
- 资源卡片展示封面、标题、摘要、标签、点赞数、评分
- 分类导航支持横向滚动

---

### 2. 搜索结果页 (`search.html`)

**路由**: `/search`

**布局结构**:
```
├── 顶部导航栏
├── AI 搜索解析提示区 (紫色渐变背景)
│   └── 解析后的结构化条件标签 (关键词/排序/数量)
├── 左侧筛选面板 (固定定位)
│   ├── 分类筛选 (复选框)
│   ├── 标签筛选 (标签组)
│   ├── 评分筛选 (单选)
│   └── 资源类型筛选 (复选框)
└── 右侧结果区
    ├── 结果统计 + 排序切换 (评分最高/最新/最热)
    └── 结果列表 (行卡片，含封面/标题/摘要/标签/元信息)
```

**核心交互**:
- AI 解析提示区展示自然语言查询的结构化拆解结果
- 筛选面板支持多维度组合筛选
- 结果卡片展示评分、浏览量、点赞数等元信息

---

### 3. 资源详情页 (`detail.html`)

**路由**: `/resource/:id`

**布局结构**:
```
├── 顶部导航栏
├── 面包屑导航
├── 主内容区
│   ├── 资源头部 (标题/标签/评分/发布者信息)
│   ├── AI 智能摘要 (紫色渐变卡片)
│   ├── 资源描述 (Markdown 渲染)
│   ├── 文件下载区
│   ├── 操作栏 (点赞/收藏/分享/我的评分)
│   └── 评论区
│       ├── 评论输入框
│       └── 评论列表 (支持二级回复)
└── 侧边栏
    ├── 相关推荐 (AI 推荐)
    └── 热门标签
```

**核心交互**:
- AI 摘要由后端自动生成，约 100 字精准概括
- 点赞/收藏按钮有 hover 状态切换
- 评分组件支持 1-5 星点击
- 评论支持一级评论和二级回复，作者评论带 `作者` 标签
- 侧栏相关推荐基于当前资源标签和用户行为生成

---

### 4. 发布资源页 (`publish.html`)

**路由**: `/publish`

**布局结构**:
```
├── 顶部导航栏
└── 表单区域 (单列布局，max-width 4xl)
    ├── 资源标题 (文本输入，限 100 字符)
    ├── 资源分类 (下拉选择，支持子分类)
    ├── 标签输入 (标签组 + 输入框 + 推荐标签)
    ├── 详细描述 (Markdown 编辑器，含工具栏)
    ├── 资源类型 (文件上传 / 外部链接 单选切换)
    ├── 文件上传区 (拖拽上传，含已上传文件列表)
    ├── 封面图片 (可选，图片上传)
    ├── AI 智能摘要提示 (说明发布后自动生成)
    └── 操作按钮 (存为草稿 / 预览 / 发布资源)
```

**核心交互**:
- 标签输入支持回车添加、点击删除、推荐标签一键添加
- Markdown 编辑器工具栏包含加粗/斜体/标题/列表/代码/链接/预览
- 资源类型切换文件上传和外部链接两种模式
- 文件上传支持拖拽，展示上传进度条
- AI 摘要为自动生成提示，无需用户操作

---

### 5. 个人中心 (`profile.html`)

**路由**: `/profile`

**布局结构**:
```
├── 顶部导航栏
├── 左侧资料卡 (固定定位)
│   ├── 头像 + 昵称 + 用户名 + 角色标签
│   ├── 个人简介
│   ├── 统计数据 (发布数/获赞/收藏)
│   └── 导航菜单 (个人信息/我的发布/我的收藏/学习统计)
└── 右侧内容区
    ├── Tab 切换 (我的发布/我的收藏/学习统计/编辑资料)
    ├── 资源列表
    │   └── 资源行卡片 (封面/标题/状态标签/操作按钮)
    └── 学习统计卡片 (总浏览量/总获赞/平均评分/总收藏)
```

**核心交互**:
- 资源状态标签：`已发布`（绿色）、`审核中`（黄色）
- 每条资源提供编辑和删除操作按钮
- 统计卡片展示发布者的全局数据概览
- Tab 切换展示不同维度的个人数据

---

### 6. 管理后台 (`admin.html`)

**路由**: `/admin`

**布局结构**:
```
├── 左侧深色侧边栏
│   ├── Logo + "管理后台"
│   ├── 导航菜单 (仪表盘/用户管理/资源审核/分类管理/标签管理)
│   │   └── 资源审核带红色角标 (待审核数量)
│   └── 管理员信息
└── 右侧主内容区
    ├── 顶部栏 (页面标题/通知按钮/返回前台链接)
    ├── 统计卡片 (总用户/总资源/待审核/今日活跃)
    ├── 待审核资源列表 (快速通过/拒绝操作)
    ├── 最近注册用户列表
    ├── 分类管理 (树形结构，支持编辑/删除)
    └── 标签管理 (标签组，含使用次数和删除)
```

**核心交互**:
- 侧边栏深色主题，与前台风格区分
- 统计卡片展示同比上周/昨日的增长率
- 待审核资源支持一键通过/拒绝
- 分类管理展示树形层级结构
- 标签管理展示使用次数，支持删除

## 设计规范

### 色彩系统

| 用途 | 颜色 | Tailwind 类 |
|------|------|------------|
| 主色 | #3B82F6 | `primary-500` |
| 成功 | #10B981 | `emerald-500` |
| 警告 | #F59E0B | `amber-500` |
| 错误 | #EF4444 | `red-500` |
| 背景 | #F8FAFC | `slate-50` |
| 文本 | #1E293B | `slate-800` |

### 响应式断点

| 断点 | 宽度 | 说明 |
|------|------|------|
| sm | 640px | 手机横屏 |
| md | 768px | 平板 |
| lg | 1024px | 小桌面 |
| xl | 1280px | 桌面 |
| 2xl | 1536px | 大屏 |

### 组件规范

- **卡片**: 圆角 `rounded-xl`，阴影 `shadow-sm`，边框 `border-slate-200`
- **按钮**: 主操作 `bg-primary-500`，次要操作 `border` 边框样式
- **标签**: `rounded` 小圆角，按分类使用不同背景色
- **输入框**: `border-slate-300`，聚焦时 `ring-2 ring-primary-500`
